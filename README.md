# Local Media Hub

このアプリは、ローカルネットワーク内で画像や動画を共有・管理・閲覧するための高機能メディアビューアーです。

## 主な機能と使い方

### 1. 閲覧と整理
- **並べ替え**: ファイルは自動的に「拡張子（Ext）順」で並びます。同じ拡張子の場合は名前順（数値考慮）で並びます。
- **検索と絞り込み**: 右上の検索ボックスでファイル名やタグをリアルタイム検索できます。また、ヘッダーのタグバーをクリックすることで、人気のタグによるクイック絞り込みが可能です。
- **フォルダプレビュー**: フォルダ内に画像がある場合、最大4枚の画像がグリッド表示（Windows風）され、中身をひと目で確認できます。
- **すべて選択**: ヘッダーのチェックアイコンから、表示されているアイテムを一括で選択・解除できます。
- **管理機能**: 「フォルダ作成」のほか、現在のフォルダ自体の「名前変更」や「削除」も可能です。

### 2. スライドショー機能
- **範囲設定**: フォルダ内の「何番目から何番目まで」を再生するか、数字を入力して範囲を指定できます。
- **選択アイテムのみ再生**: ファイルを複数選択した状態で、画面下部の一括操作バーにある「スライドショー(再生アイコン)」を押すと、選択したファイルだけでスライドショーを開始できます。
- **再生速度**: 「Secs」の欄で切り替え秒数を変更できます。
- **ループ再生**: 最後の画像まで到達すると、自動的に最初の画像に戻って再生を続けます。
- **動画対応**: 動画ファイルの場合は、再生が終わるまで自動的に待機してから次のスライドへ進みます。

### 3. 画像の拡大（ズーム）表示
- 画像表示中に画像自体をクリックするか「拡大」ボタンを押すと全画面表示になります。
- 全画面表示中はマウスやタッチ操作で自由にスクロールして細部を確認できます。
- スライドショー中に拡大した場合、ズーム状態を維持したまま次の画像へ切り替わります。

### 4. タグ付け
- 画像詳細画面の「+」ボタンから、既存のタグを選択するか新規入力でタグを追加できます。
- タグをクリックするとそのタグで絞り込んだ状態でフォルダに戻り、`×`をクリックするとタグを削除できます。

### 5. ファイル管理と一括操作
- **アップロード**: 「アップロード」ボタンから新しい画像や動画を追加できます（ルートフォルダ以外で有効）。
- **移動**: 画像の下にある「別のフォルダへ移動する」ボタンから、クリック操作で簡単にファイルを移動できます。
- **一括操作**: 複数のアイテムを選択すると画面下にアクションバーが表示され、「スライドショー再生」「タグの一括追加」「一括移動」「一括削除」をまとめて行えます。

## 操作のコツ
- **戻る**: 画面上の「フォルダに戻る」で一覧に戻れます。
- **スワイプ**: タッチパネルやマウスドラッグで画像を左右に払うことで、前後移動が可能です。
- **ヘルプ**: フォルダ一覧の右上にある `?` アイコンから、いつでもこのREADMEを確認できます。

## 開発者向け

### 実行方法
1. 依存関係のインストール: `npm install`
2. 開発用サーバーの起動: `npm run dev`
4. ブラウザでアクセス: `http://localhost`

### データの保存場所
- 画像実体: `/images` フォルダ配下
- タグ/メタデータ: `/.metadata.json`（自動リロードを避けるため隠しファイルになっています）
