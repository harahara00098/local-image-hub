 # Local Image Hub マニュアル

このアプリケーションは、ローカル環境にある画像や動画を快適に閲覧・管理するためのWebアプリケーションです。

---

 ## 主な機能

 ### 1. 閲覧機能
- **フォルダ/ファイルブラウジング**: 直感的なUIでフォルダを移動し、画像や動画を閲覧できます。
- **多彩なプレビュー**:
    - **画像**: サムネイルをクリックすると拡大表示できます。
    - **動画**: サムネイルと、クリックで再生可能なプレーヤーが利用できます。
    - **フォルダ**: フォルダの中身のメディア（画像・動画）が最大4つまでプレビュー表示されます。
- **一覧表示モード**: 孫階層のフォルダ（例: `/comics/one-piece`）を開いている際、`一覧表示`ボタンを押すと、そのフォルダ配下の全メディアを1ページでまとめて閲覧できます。
- **キーボード/スワイプ操作**: 画像/動画表示中に、キーボードの `←` `→` キーや、画面のスワイプで前後のメディアに素早く移動できます。

 ### 2. スライドショー
- **範囲指定再生**: フォルダ内のメディア番号を指定して、特定の範囲だけをスライドショー再生できます。
- **選択再生**: 複数選択したメディアだけを対象にスライドショーを開始できます。
- **秒数設定**: 画像の切り替え秒数を自由に設定できます。
- **操作**: `Space`キーでスライドショーの開始・停止が可能です。

 ### 3. タグと検索
- **タグ付け**: ファイルやフォルダに自由にタグを追加・削除できます。
    - **フォルダタグ**: フォルダに付けたタグは、その中のすべてのファイルやサブフォルダに自動で継承されます。
- **タグ絞り込み**: 画面上部のタグ一覧から、表示するアイテムを絞り込めます。複数選択するとAND検索になります。
- **キーワード検索**: 画面右上の検索ボックスから、ファイル名やタグ名でアイテムを検索できます。

 ### 4. ファイル・フォルダ管理
- **アップロード**: 現在のフォルダに画像や動画をアップロードできます。
- **新規フォルダ作成**: 現在の場所に新しいフォルダを作成できます。
- **名前の変更**: ファイルやフォルダの名前を変更できます。
- **移動**: ファイルやフォルダを別の場所に移動できます。
- **削除**: ファイルやフォルダを削除できます。

 ### 5. 一括操作
- アイテムの右上のチェックボックスをクリックすると複数選択モードになります。
- 画面下部に表示されるアクションバーから、選択したアイテムに対して以下の操作を一括で行えます。
    - タグの追加
    - スライドショーの開始
    - 移動
    - 削除

 ## キーボードショートカット

より快適に操作するためのショートカットが用意されています。

| キー | アクション |
|:---|:---|
| `←` / `→` | 前後のメディアへ移動 |
| `Esc` | 拡大表示の終了 / フォルダに戻る |
| `Space` | スライドショーの再生・一時停止 / 開始 |
| `/` | 検索ボックスへフォーカスを移動 |
| `H` | ホーム画面に戻る |
